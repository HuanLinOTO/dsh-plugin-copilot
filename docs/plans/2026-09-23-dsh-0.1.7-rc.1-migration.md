## 改动

**Host**
- `src/index.ts`
  - `Config.enterpriseDomain` → `Volatile<string>` + schema `.volatile()`；
  - 删除 `ctx.settings.register(CARD_NAMESPACE, Config)`，改为 `ctx.inject(['settings'], child => child.effect(() => child.settings.configure({ auto: false }, ctx.fiber)))`（插件自带卡片，禁用 schema 自动页）；
  - `piAiSection()` 的 `settings.get(PI_AI_NS)` → `settings.describe().find(row => row.ns === PI_AI_NS)?.value`（rc.1 `SettingsForms` 无 `get`）；
  - gateway 传 `enterpriseDomain: () => config.enterpriseDomain.get()`（读取实时 volatile 值）。
- `src/gateway.ts`：`GatewayDeps.enterpriseDomain` 接受 `string | (() => string)`，prompt 回答时解引用。
- `@deepseek-ai/schemastery`（裸包，最高 3.18.0，**无** `.volatile()`）→ `@deepseek-ai/schemastery ^3.18.4`。

**Web Client**
- `src/client/index.ts`：`settings.plugin.item` → `plugins.row.config`，key `@huanlin/dsh-plugin-copilot#dsh-plugin-copilot`（bundle 的 patch 声明 row id `dsh-plugin-copilot`）；`dsh.client.inject` 增 `@deepseek-ai/dsh-client-ui-plugin-manager`。
- `src/client/CopilotAuthCard.tsx`：props 增 `PropsRuntime<'plugins.row.config'>`，`view === 'summary'` 渲染 `t('card.intro')`（hooks 之后分支，避免 hook 顺序问题）。

**打包/配置**
- `package.json` peer/meta：`dsh-*` → `^0.1.7-rc.1`，`dsh-client-ui-settings-plugins` → `dsh-client-ui-plugin-manager`；`dsh.client.inject` 同步。
- `tsconfig.json`：paths 增 `ui-plugin-manager`（root + `/client`），删 `ui-settings-plugins`。
- `tsdown.config.ts`：HOST_EXTERNALS 的 `schemastery` → `@deepseek-ai/schemastery`。
- 重建 `lib/`（host + client bundle + `lib/types`）；`pnpm-workspace.yaml`/`pnpm-lock.yaml` 由 `pnpm install` 更新（新增 `dsh-client-ui-plugin-manager@0.1.7-rc.1` 等 minimumReleaseAgeExclude）。
